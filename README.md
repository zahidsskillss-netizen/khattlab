# NawakhtGar

(پخوانی نوم: KhattLab)

د غوره ګرافیکس پرودکشن (Ghora Graphics) لخوا پر عکسونو د متن لیکلو او ډیزاین اپ.
جوړونکی: Zahid Ullah Alokozay

## نسخه 2.3 کې نوي شیان

- **ازاد پرسپکټیو:** د پرسپکټیو برخه چې خلاصه شي، د انتخاب شوي شکل/عکس/متن پر څلورو کونجونو ګردې نښې راځي؛ هر کونج جلا په ګوته کش کېږي (د PixelLab په څېر) — افقي/عمودي سلایډرونه هم شته
- **هر کونج جلا ګردول:** ګرد مربع او خبرو بلبله کې «ټول کونجونه» سلایډر پر ځای پاتې دی، او لاندې یې د هر کونج جلا سلایډر (پورته کیڼ، پورته ښي، لاندې ښي، لاندې کیڼ) — د عکسونو ګردوالي کې هم

## نسخه 2.0 کې نوي شیان

- **پروژې:** هر ډیزاین پخپله د پروژې په توګه ساتل کیږي؛ وروسته خلاصیږي او ټول متنونه او عکسونه یې بیا سمېدای شي (نوم بدلول، کاپي، ړنګول)
- **3D متن (د PixelLab په څېر):** فعال/بند، پرسپکټیو یا مایل، ژوروالی او لوری، د ژوروالي رنګ (رنګ / اتومات / ګرېډینټ)، تیاره کول، X/Y/Z څرخول، د رڼا شبیه‌سازي او زاویه
- هر نوی APK پر زاړه نصبیږي (یو ثابت کیلي)

## لومړی پړاو کې څه شته

- له ګالري عکس راوړل، یا رنګه پاڼه (1:1، 4:5، 9:16، 16:9، 3:4، A4)
- څو متنونه: رنګ، فونټ، اندازه، څرخول، څنډه (stroke)، سیوری، روڼوالی، برابرول، د تورو او کرښو واټن، د متن شالید
- پښتو، دري، عربي او انګلیسي سم ښودل (RTL)
- په یوه ګوته متن ځایول، په دوو ګوتو لویول او څرخول، دوه ځله ټکول = متن سمول
- بېرته / مخکې (Undo / Redo)
- له تلیفون نه فونټ (.ttf / .otf) راوړل
- په ګالري کې په بشپړ کیفیت خوندي کول (Pictures/NawakhtGar) او شریکول
- له ګالري نه «شریکول ← NawakhtGar» سره عکس مستقیم اپ ته راځي

## APK څنګه جوړ کړئ (پرته له Android Studio)

1. په GitHub کې نوی repository جوړ کړئ، نوم: `khattlab`
2. د دې zip ټول فایلونه (د `.github` فولډر په ګډون) پکې اپلوډ کړئ
3. **Actions** ته لاړ شئ ← «Build NawakhtGar APK» به پخپله پیل شي
4. کله چې شین ✓ شو، په هغې کلیک وکړئ ← لاندې **Artifacts** ← `NawakhtGar-apk` ښکته کړئ
5. zip خلاص کړئ او `app-debug.apk` په تلیفون نصب کړئ

## خپل فونټونه له اپ سره یوځای کول

هر `.ttf` یا `.otf` فونټ (لکه بهیج) د `app/src/main/assets/fonts/` فولډر ته واچوئ.
بیا جوړ شي، په اپ کې به د فونټونو په لیست کې ښکاره شي.

## راتلونکي پړاوونه

- **دویم:** سټیکرونه، شکلونه، فلټرونه، روښانتیا/کنټراست، پرې کول (crop)، لېیرونه
- **درېیم:** 3D متن، د شالید لرې کول، ټیمپلېټونه، پروژه خوندي کول او وروسته بیا سمول
